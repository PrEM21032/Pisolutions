## Reproduced (on 9ec0def, 14:36Z)
`ln -s "$PWD/worker/scripts/validate-deploy-configuration.mjs" /tmp/l.mjs && env -i PATH=$PATH node /tmp/l.mjs; echo $?` gives `0` with no output.
Cause: Node resolves the main module's real path for `import.meta.url`, but `argv[1]` keeps the link path, so the guard was false.

## Fix
The entry-point guard now compares `realpathSync(argv[1])` with `realpathSync(fileURLToPath(import.meta.url))`.
After the fix, the same command exits `1` and prints name-only messages.
