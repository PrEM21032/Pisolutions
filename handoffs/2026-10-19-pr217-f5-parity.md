## How it works
1. Extracts the `run:` scripts of "Configure optional independent fallback provider" and "Configure optional
   Stripe billing" from `.github/workflows/pi-chat-worker.yml`. If a step or its `set -euo pipefail` is
   missing, extraction fails loudly.
2. Runs them under `bash` with `env -i`-style env and `PATH=<stubs>:/usr/bin:/bin`. It stubs:
   - `curl`: returns an active recurring Price, with livemode=true when the bearer contains "live"; no network;
   - `npx`: records the call and swallows stdin; no wrangler;
   - `python`: execs the local python/python3.

   Each run aborts with exit 97 unless `curl` and `npx` resolve to the stubs.
3. Compares the shell's accept/refuse with `validateDeployConfiguration()` for 45 inputs:
   - every presence subset for fallback and Stripe;
   - key, webhook and price near-misses;
   - whitespace-only values and a trailing newline.

   It also requires that both accept and refuse outcomes are seen for each provider, so the test can't pass
   vacuously.
