## Reproduction (Linux, on 1cf9229)
- Running `node "<dir with space>/pi/continuity-handoff.mjs" --evidence e.json --out out.md` exits 0 and writes no file.
- Running through a symlinked entry also exits 0 and writes no file.
- A plain path works.
- Root cause: `import.meta.url` is a percent-encoded `file:///` URL, and it was compared to the raw
  `file://${argv[1]}` string. On Windows that string is `file://C:\...` and never matches `file:///C:/...`
  (Codex's report).
- Not executed on Windows here. Codex's comment 6275322863 returned 403 from this session.

## Fix (production diff: +14/-1 in pi/continuity-handoff.mjs)
`isEntryPoint(argv[1])` compares `realpathSync(argv[1])` with `realpathSync(fileURLToPath(import.meta.url))`.
